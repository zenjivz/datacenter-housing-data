# Data Centers and Housing in Virginia

I put these datasets together to look at how home values and rents changed in parts of Virginia with a lot of data center development. This repo has the data, not the analysis.

## What’s in here

- [Data center locations](businessinsider_data_centers_data.xlsx): The Business Insider facility spreadsheet.
- [Home values in the focus counties](zhvi_long_va_focus.csv): Monthly Zillow Home Value Index (ZHVI) data by ZIP code.
- [Cleaned home values for the comparison sample](zhvi_long_va_comparison_clean.csv): Start here if you want to compare home values across counties. The [earlier version](zhvi_long_va_comparison.csv) is also included.
- [Rents in the focus counties](zori_long_va_focus.csv): Monthly Zillow Observed Rent Index (ZORI) data by ZIP code.
- [Census tract data](nhgis_tract_long.csv) and [Virginia focus subset](nhgis_tract_long_va_focus.csv): American Community Survey data via NHGIS, including population, household income, and housing occupancy and vacancy.

The source datasets are subject to their original providers’ terms.
